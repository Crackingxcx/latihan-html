# PERMADI NETWORK Website

Website ini dibuat berdasarkan desain screenshot yang kamu kirim.

## Struktur

- `index.html` — struktur halaman
- `styles.css` — seluruh styling/layout/responsive
- `script.js` — menu mobile, scroll reveal, tahun footer, active navigation

## Cara menjalankan

1. Extract folder.
2. Buka `index.html` di browser.
3. Tidak membutuhkan framework.
4. Gambar contoh menggunakan URL gambar eksternal dari Unsplash. Jika ingin website production, sebaiknya download/ganti dengan asset milik sendiri.
